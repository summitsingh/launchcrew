## Auth status notes, Oct 31, 2026

Auth was VERIFIED LIVE with Google sign-in only. Authlib in FastAPI was the sole source of truth. Live Google OAuth sign-in succeeded in browser, and per-actor workspace isolation was verified across distinct authenticated sessions (M13, commit 3823219). Facebook Login was removed from the proposal scope per owner direction (M4, commits 051e63f and bffb324). Opt-in configuration used AUTH_ENABLED=true, HTTPS PUBLIC_BASE_URL, and GOOGLE_CLIENT_ID plus GOOGLE_CLIENT_SECRET supplied at runtime outside files and logs. Google requested openid, profile, email. Routes used Authlib state and nonce handling, persisted state and identity only in Postgres sessions, rotated an opaque random session cookie, and never retained provider tokens. Cookies were Secure, HttpOnly, SameSite=Lax, with an eight hour expiry. Only hashed cookie identifiers were stored server-side.

## Backend model API notes, Oct 27 to Oct 31, 2026

Model calls used the existing portal key via environment only, read by FastAPI from META_API_KEY at runtime. No key was placed in a repo file, frontend, database, receipt, build, or container configuration. Three creation paths could call models, each under explicit gates, all through backend/adapter.py execute: POST /api/runs (synchronous), POST /api/runs/async (one background worker per run id with stored step rows), and POST /api/campaigns (seven runs, one per day brief). Each run did Spark text synthesis (optional configured Wonder synthesis with Spark fallback) for Scout, Maker, and Checker candidates. POST /api/runs/{run_id}/photo-check ran paid SAM segmentation only after an explicit Check click passed every photo gate. No SAM call happened on any run, progress, or campaign path. Every candidate passed deterministic checks against demo facts. Unverified Scout facts were excluded from Maker. Maker accepted checked allowlist sentences only. Checker suggestions never decided verdicts, approved, unblocked, or verified claims. Final drafts, auth, connectors, database operations, approval and export gates remained deterministic.
