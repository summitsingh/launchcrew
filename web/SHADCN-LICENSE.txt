Components added via the shadcn CLI (shadcn/ui, MIT):
calendar, collapsible, dialog, dropdown-menu, form, select, sheet, sidebar,
skeleton, sonner, table, tooltip.
Pre-existing local primitives kept as-is for the classic workspace:
alert, badge, button, card, input, label, separator, tabs, textarea.
Local adaptations: calendar day/nav buttons and the sidebar trigger render as
plain buttons (no dependency on the classic Button styles); Radix primitives
are imported from scoped @radix-ui/react-* packages.
